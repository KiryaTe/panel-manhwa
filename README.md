# Panel — локальная библиотека манхвы

## Возможности
- Добавление тайтлов и глав из изображений или ZIP/CBZ.
- Вертикальное чтение в тёмном режиме.
- Автоматическое сохранение последней главы и страницы.
- Хранение библиотеки в IndexedDB на устройстве.
- PWA-установка на Android и офлайн-оболочка.

## Запуск на Android
Для установки PWA нужен HTTPS-адрес (или localhost). Самый простой вариант для первого теста:
1. Распакуй архив на компьютере.
2. Размести содержимое папки на любом статическом хостинге с HTTPS (например, GitHub Pages).
3. Открой полученный HTTPS-адрес в Chrome на Android.
4. В меню Chrome выбери «Установить приложение» / «Добавить на главный экран».

Можно также открыть `index.html` локально для проверки в браузере, но установка PWA и service worker при `file://` работать не будут.

## Импорт
- Для одной главы выбери сразу все изображения страниц.
- Или выбери ZIP/CBZ с изображениями JPG, PNG, WEBP, GIF или AVIF.
- Имена файлов определяют порядок страниц: `001.jpg`, `002.jpg`, `003.jpg`.
- Чтобы добавить следующую главу, открой тайтл → «Добавить главу».

## Хранение и резервная копия
Данные и изображения остаются в хранилище браузера на телефоне. Не очищай данные сайта/браузера, иначе библиотека может быть удалена. В этой первой версии экспорт резервной копии ещё не реализован.
